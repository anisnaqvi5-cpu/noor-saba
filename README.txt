نورِ صبا — شیعہ تقویم پاکستان (PWA)
===================================

فائلیں
------
index.html                 ← پوری ایپ (اذان کی آواز اندر شامل ہے)
manifest.webmanifest       ← ایپ کی شناخت (نام، آئیکون، رنگ)
sw.js                      ← service worker (آف لائن کام کرنے کے لیے)
icon-192.png               ← آئیکون
icon-512.png               ← آئیکون
icon-maskable-512.png      ← اینڈرائیڈ کا گول/ماسک آئیکون
apple-touch-icon.png       ← آئی فون کا آئیکون
favicon-64.png             ← براؤزر ٹیب کا آئیکون

اہم: ساری فائلیں ایک ہی فولڈر میں، ایک ساتھ اپلوڈ ہونی چاہیئیں۔


آن لائن کرنے کا طریقہ (دو آسان راستے)
--------------------------------------

1) Netlify Drop — سب سے آسان، مفت
   • https://app.netlify.com/drop کھولیں
   • یہ پورا فولڈر صفحے پر ڈریگ کر دیں
   • فوراً ایک لنک مل جائے گا، مثلاً  https://noor-saba.netlify.app
   • وہی لنک واٹس ایپ/ٹیلی گرام میں بھیج دیں

2) GitHub Pages — مفت، اپنے اکاؤنٹ پر
   • ایک نیا repository بنائیں
   • یہ ساری فائلیں اپلوڈ کریں
   • Settings → Pages → Branch: main → Save
   • لنک: https://<آپ کا نام>.github.io/<repo>/


ضروری بات: HTTPS
-----------------
service worker اور "ہوم اسکرین پر شامل کریں" صرف https:// پر کام کرتے ہیں۔
Netlify اور GitHub Pages دونوں خود بخود https دیتے ہیں — کچھ کرنے کی ضرورت نہیں۔
اگر index.html کو صرف فون میں فائل کی طرح کھولیں گے تو ایپ چلے گی، مگر
نصب (install) اور آف لائن کیشنگ نہیں ہوں گے۔


انسٹال کیسے ہوگا
-----------------
لنک کھلنے پر اوپر ایک سنہری پٹی آئے گی: "نورِ صبا کو ہوم اسکرین پر شامل کریں"۔
"نصب کریں" دبانے سے آئیکون ہوم اسکرین پر آ جائے گا اور ایپ پورے اسکرین پر
کھلے گی — براؤزر کا ایڈریس بار نظر نہیں آئے گا۔
آئی فون پر: Share → "Add to Home Screen"۔


اپ ڈیٹ کرنے کا طریقہ
---------------------
جب کوئی تبدیلی کریں:
  1. نئی index.html اپلوڈ کریں
  2. sw.js میں CACHE کا نام بدل دیں، مثلاً "noor-saba-v1" → "noor-saba-v2"
اس سے صارفین کے فون پر پرانا کیش خود بخود صاف ہو کر نیا ورژن آ جائے گا۔
(نام نہ بدلیں تو پرانا ورژن ہی چلتا رہے گا۔)


آنے والے کام (یاد دہانی)
-------------------------
• قمری مہینوں کا جدول دسمبر 2026 (رجب 1448) تک ہے — 2027 کے لیے انجمنِ
  حسینی کا نیا نقشہ درکار ہوگا۔ اُس کے بعد ایپ خود فلکیاتی حساب پر آ جائے
  گی، جس میں کبھی ایک دن کا فرق آ سکتا ہے۔
• پس منظر میں اذان (background notification) کے لیے اگلا مرحلہ درکار ہے۔
• صارف کی منتخب کردہ MP3 ابھی محفوظ نہیں رہتی (IndexedDB سے حل ہوگی)۔
